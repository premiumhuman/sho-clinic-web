# 新宿御苑しょうクリニック

HTML、CSS、JavaScriptで制作した静的サイトです。サイトのコードと画像は `public/` にあります。

## ローカルプレビュー

Python 3とnpmが利用できる環境で、リポジトリ直下から起動します。

```sh
npm run dev
```

[ローカルプレビュー](http://127.0.0.1:4322/)を開きます。

トップページの波形と写真の拡大は `public/styles.css`、写真の順番は `public/index.html`、自動切り替えと一時停止は `public/site.js` で設定しています。
